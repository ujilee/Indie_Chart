# 인디차트 기획 요약

> 2026-11-11 전달받은 기획문서의 핵심 정책 요약. 구현 시 기준 문서로 사용.

## 1. 서비스 개요
- 국내 인디 아티스트의 음악 플랫폼 활동 + 팬 관심도 + 공연 활동 + 사용자 응원을 종합한 **아티스트 단위** 차트
- 차트: 일간 / 주간 / 월간 / 연간 (기본: 일간)
- 데이터 수집: 매일 01:00 KST, 수집·계산 완료 후 차트 갱신
- 순위 변동: 같은 차트 유형의 직전 기간과 비교
- 로그인: 이메일 회원가입·로그인 + 소셜 로그인(카카오·Google) (응원에만 필수)
- 아티스트·공연 등록: 관리자 등록 또는 사용자 제보 → 승인

## 2. 점수 (최대 120점)
| 지표 | 계산 | 최대 |
| --- | --- | --- |
| 멜론 차트 순위 | 곡 점수 = 101 − 순위, 상위 5곡 합 ÷ 5 → ×0.10 | 10 |
| 멜론 전체 곡 좋아요 | 전체 곡 증가량 합 ÷ 만점기준 ×100 (≤100) → ×0.36 | 36 |
| 멜론 팬맺기 | 증가량 ÷ 만점기준 ×100 → ×0.22 | 22 |
| Spotify 팔로워 | 증가량 ÷ 만점기준 ×100 → ×0.22 | 22 |
| 사용자 응원 | 기간 응원수 ÷ 기간 최다 응원수 ×100 → ×0.10 | 10 |
| **기본 점수** | | **100** |
| 공연 가점 | 유효 공연 1건당 +4 (최대 5건) | +20 |

- 일간 만점 기준(임시): 좋아요 100개, 팬 100명, 팔로워 100명. 주/월/연 기준은 데이터 분석 후 설정(변경 이력 관리)
- 증가량 ≤ 0 → 0점, 곡별 좋아요 감소는 0 처리, 수집 실패는 0점이 아닌 "미수집"
- 기간 집계: 외부 수치는 기간 순증가량, 곡 순위·공연 가점은 일별 평균
- 응원 집계 기간: 일간=전일, 주간=전주 월~일, 월간=전월, 연간=전년도
- 최종 순위는 반올림 전 점수 기준, 동점은 공동 순위 + 다음 순위 건너뛰기
- 일부 아티스트 수집 실패 시 순위 확정하지 않음
- 대체안: Spotify 확보 불가 시 멜론 단독(순위10/좋아요40/팬40/응원10, 공연 +15)

## 3. 공연 가점
- 대상: 관리자 승인 + 향후 30일 이내 개최 예정 공연 (공연 당일 23:59:59까지)
- 취소·종료 공연 제외, 동일 공연 1건만 인정, 다회차는 날짜별 인정
- 30일 초과 미래 공연도 제보 가능 (30일 이내 진입 시 반영), 종료/취소 공연은 신규 제보 불가

## 4. 응원
- 로그인 회원, 하루 총 1회(1팀), 00:00 KST 초기화, 취소 불가, 부정 응원은 무효 처리
- **월간 응원 TOP 3**: 당월 누적 유효 응원 횟수 순위 (점수 환산 없음), 공동 순위 모두 노출(3팀 초과 가능), 동률은 가나다순, 0회 제외, 전체 0건이면 빈 상태 안내
- 진행 중: "이번 달 응원 아티스트 TOP3" / 종료 후: "지난달 최종 응원 TOP3"

## 5. 월간 최종 종합 TOP 3 (홈 상단 고정)
- 직전 완료 월의 월간 종합 차트 1~3위 (공동 순위 포함), 기준 연월 표시
- 차트 탭 변경과 무관하게 고정, 월간 집계 확정 후 갱신

- 사용자 화면에는 점수 미노출, 순위·변동만 (순위 산정 기준은 가이드로 안내)
- 순위 변동 표시: ▲N / ▼N / — / NEW
- 데이터 없는 지표는 "데이터 확보 중"
